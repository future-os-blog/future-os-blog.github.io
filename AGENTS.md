# AGENTS.md — working conventions for this repository

Conventions the user has asked every agent to keep, that are not derivable
from the code alone.

## Answering while editing a blog post

**When editing a blog post (anything under `blog/posts/`), always include links
to both generated Markdown files in your final reply — the English source
(`blog/posts/YYYY-MM-DD-slug.md`) and the Chinese mirror
(`blog/posts/zh/YYYY-MM-DD-slug.md`).**

Link them as file paths so the user can open the current state of the article
in both languages without hunting through the repository. Link both files after
every revision round; do not paste their text, and do not substitute a summary
for the links.
